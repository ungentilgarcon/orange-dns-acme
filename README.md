# orange-dns-acme

Scripts to renew Let's Encrypt certificates using the DNS-01 challenge,
publishing the required TXT record via the **Orange Business Cloud DNS
API**. Includes an [acme.sh](https://github.com/acmesh-official/acme.sh)
DNS hook, a cron-friendly renewal wrapper with email notifications, and
setup docs for Debian/Ubuntu (native, WSL, or Git-Bash on Windows).

See [dns-acme/README.md](/dns-acme/README.md) for full documentation.
